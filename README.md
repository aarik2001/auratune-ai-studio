# 🎸 AuraTune AI // DSP & Neural Music Workstation

An advanced AI-powered, emotion-driven music production studio built with Streamlit, OpenRouter LLM, ACE-Step 3.5B Cloud Diffusion, and a multi-track Librosa Digital Signal Processing (DSP) telemetry suite.

---

## ✨ Key Features
- **Emotion & Music Theory Engine:** Analyzes user prompts to determine psychoacoustic vectors, keys, tempos, and harmonic chord progressions.
- **AI Songwriter (OpenRouter):** Generates structured song lyrics and style production tags.
- **Neural Singing & Band Synthesis (ACE-Step):** Generates studio master tracks with actual singing vocals and multi-instrument backing bands.
- **Advanced DSP & Spectral Suite (`Librosa`):** Provides a 4-panel acoustic oscilloscope suite (Waveform RMS, 12-Tone Chromagram, HPSS Stem Decomposition, and Spectral Centroid/Rolloff).
- **Glassmorphism Dark-Mode UI:** Professional studio aesthetic with custom CSS styling and a real-time vocal teleprompter.
